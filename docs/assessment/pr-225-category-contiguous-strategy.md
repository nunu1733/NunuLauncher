## Criteria check

- **Spec §CATEGORY_CONTIGUOUS_V1 rule 1 (catalog row: eligible movable units) — PASS.** The registry filter requires kind `APPLICATION`/`DEEP_SHORTCUT` **and** `CapturedPlacement.Workspace` span exactly `GridSpan(1,1)`. The available/unlocked/top-level clauses are enforced upstream and unchanged: `movableItems` = items with `determinePreservation == null`, which preserves locked (`LOCKED`), unavailable (`UNAVAILABLE_TARGET`), reserved-overlap, dock, widget, app-pair, legacy-shortcut, non-target, and `FolderMember` placements (`STRUCTURAL`) — so the eligible set is exactly "available, unlocked, top-level `1×1` `APPLICATION`/`DEEP_SHORTCUT`". The closed movable-kind analysis (same as the child-6 audit) leaves `APPLICATION`, `DEEP_SHORTCUT`, and top-level `FOLDER` as the only movables, so `strategyFixed` is exactly the spec's fixed set (existing folders + non-`1×1` movables), each `markOccupied` at its captured cell before any allocation and reported `Preserved(STRATEGY_PRESERVED)` with its captured target — truthful per §Strategy-preserved rationale ("existing folders under `CATEGORY_CONTIGUOUS_V1`"), never `ALREADY_CANONICAL`/`NON_TARGET`.
- **Spec §CATEGORY_CONTIGUOUS_V1 rule 2 (catalog row: per page unit order) — PASS.** `categoryContiguousOrder` is `compareBy(profile, fallbackRank, category, targetKeySortValue, ItemId)`. (a) *Fallback last*: the rank key is `if (decisions[id]?.category ?: fallback == fallback) 1 else 0`; Kotlin's elvis binds tighter than `==`, so this parses as `(effectiveCategory) == fallback → 1` — the fallback category (and undecided items, which take the fallback) sorts after every named category, and the third key orders named categories by `CategoryId` `compareUtf8Bytes` (locale-independent). Empirically pinned by `categoriesOccupyContiguousBlocksInOrderWithFallbackLast` (GAMES | TOOLS | OTHER blocks). (b) *Canonical target key*: the spec names the key but fixes no encoding (the encoding is implementation discretion, documented in the executor KDoc); `targetKeySortValue` prefixes the variant ordinal (`0:` AppKey, `1:` ShortcutKey, …) then the opaque handle values, and only the AppKey/ShortcutKey branches are reachable for eligible units. The encoding is total and deterministic — package names cannot contain `:`, so the `pkg:sid` split is unambiguous, and the final `ItemId` key (unique per `checkDuplicateItemIds`) closes every tie. (c) *Within-category ItemId tie-break*: last comparator key. All five keys are identity-based (no position, clock, locale, or thread dependence).
- **Spec §CATEGORY_CONTIGUOUS_V1 rule 2 (page-local) / catalog row page scope — PASS.** Units are grouped by their captured `PageRef` and allocated exclusively through `Allocator.allocateOnPageOnly` on that page; failure to place is a loud `error()` (the lift-then-place placeability invariant, same argument as child 4: captured layouts are valid and non-overlapping, so eligible units never exceed post-lift free cells). No page is created (`newPages = allocator.buildNewPages()` over an allocator that never appends pages on this path) and no unit crosses a page — `categoriesAreNeverPulledAcrossPageBoundaries` pins that a page-2 GAMES app is not pulled onto page 1 beside its category pair. Page-iteration order of the `groupBy` map cannot affect results: pages are allocation-independent and the output is `sortedBy { it.item }`.
- **Catalog row folder policy — create no new folders; existing folders preserved as fixed units — PASS.** `createsFolders=false` (the shared executor never calls `formFolderGroups` on this path and returns `newFolders = emptyList()`), and existing folders fail the eligible filter → `STRATEGY_PRESERVED` fixed occupancy. `tidyFormsNoFoldersEvenWhenCanonicalGroupingWouldApply` is the canonical control run: the same input under `CANONICAL_PAGE_COMPACT_V1` forms exactly one GAMES folder, so the no-folder assertion cannot pass by fallback-category accident (same review pattern as children 4–6). `strategyPreservedFixedItemsRemainOccupancyConstraints` verifies a folder and a `2×1` app block cells for the compacting units.
