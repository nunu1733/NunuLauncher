## Findings

1. **Round-1 open item AC-10 is closed** by the committed device evidence; verdicts are now PASS on all twelve spec 237 acceptance criteria. One evidence-quality caveat stands: `237-after-page2.png` duplicates `237-after-page1.png` byte-for-byte, so the committed set shows the applied front page but not a distinct "page 2 empty" frame. 2. **Device crash root cause and fix (verified, in scope of this re-audit):** during the round-1→round-2 evidence run, every on-device `GLOBAL_COMPACT_V2` run aborted right after capture with `IllegalArgumentException: strategyVersion must be an approved version identifier, got 'GLOBAL_COMPACT_V2'` — `PlanningProjection.project` constructs `RunVersions`, whose `APPROVED_VERSIONS` allowlist lacked the successor ID (the planner and picker never construct `RunVersions`, which is why 953 unit tests missed it). Fixed in `ccdb4c3389` by adding the ID (ADR-0012 extension of the approved set) and pinned by the new registry-sweep contract test. Lesson recorded for future strategy enablements: enabling a strategy must extend the diagnostics allowlist in the same change — now enforced by test.
3. **Separate pre-existing app bug (follow-up issue, not a blocker):** during device triage, `LawnchairBugReporter` failed to persist crash logs — the timestamped crash-report filename contains `/`, and the save throws `IOException`, so crash reports were silently not written. This masked the V2 crash's persistence path during triage and is unrelated to spec 237; it deserves its own issue and fix (sanitize the filename before the timestamp is embedded).
4. **Gate state at re-audit time:** the `high-risk-evidence` check fails on the branch because the committed round-1 record pinned `eba38d573d…` and non-docs commits followed it — exactly the gate working as designed. This updated record (Head SHA `ccdb4c3389…`) is the resolution; the commit carrying it must be docs-only so the audited head remains the last non-docs commit. The round-1 CI run (34088182723) and the round-2 run (34110363181) are both fully green on their respective heads.
