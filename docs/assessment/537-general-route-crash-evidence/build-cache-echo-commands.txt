# build-cache-echo実証トランスクリプト（2026-10-06 調査session）

Issue #537根因チェーン5/6（破損compile出力のbuild cache保存・復元と`--rerun-tasks`による回復）のコマンドとキャプチャ出力。出力行は調査sessionで実際に取得したものの転写である。

## 1. fresh worktree通常ビルド → クラッシュAPK（cache復元を示す行）

`git worktree add /Users/nunu/Documents/work/NunuLauncher-537-clean 575e37baad` で作成したfresh worktree（build dirは空）でのビルド。`377 from cache`はcompile task出力がlocal Gradle build cache（`~/.gradle/caches/build-cache-1`）から復元されたことを示す。復元元entryはmain worktreeの過去ビルド（クラッシュAPKを作ったincrementalビルド）が保存した破損出力。

```text
$ cd /Users/nunu/Documents/work/NunuLauncher-537-clean && ./gradlew assembleLawnWithQuickstepGithubDebug

```

生成APK `Lawnchair.16.Dev.(575e37b).github.debug.apk` をemulatorにinstallしてGeneral routeを開くと`NoSuchFieldError`でクラッシュ（[general-route-crash-logcat.txt](general-route-crash-logcat.txt)）。
